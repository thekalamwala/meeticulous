# OTP code problems

The 6-digit code we send to sign you in or confirm a booking is called an OTP. Here's how to fix the common issues.

## I didn't get the code

- Check **both WhatsApp and your email** (including the spam or promotions folder) — we send the code to both.
- Make sure the phone number and email you entered are correct.
- Codes expire after 10 minutes. If it's been longer, request a fresh one and use the newest code.

## "Too many requests" / "Try again in 15 minutes"

For security, there's a limit of 3 codes per hour. If you go over it, there's a 15-minute wait before you can request another. Wait it out, then request one more code — and enter only the newest one.

## "Invalid or expired code"

- Only the **most recent** code works — older codes stop working as soon as you request a new one.
- Codes last 10 minutes. Past that, ask for a new one.
- After 3 wrong tries there's a short lockout; wait 15 minutes and try again with a fresh code.

## Still not working?

If codes never arrive after all of that, reach us from the [Help](/help) page — occasionally it's on our side and we'll get it fixed.
